# Plex Phase 9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring Plex to feature parity with Jellyfin in Vela: music, downloads, seek-bar previews (BIF), Cast (video and music) and Android Auto.

**Architecture:** Everything Plex-specific stays in `src/backends/plex` (TS) behind the domain ports, and in a new Kotlin `PlexLibrary` behind a `MusicLibrary` interface for Android Auto. The app only gains backend-neutral fields (`MediaVersion.streamRef`, `AudioTrack.streamRef`, `MediaBackend.castMode`) and reads capabilities.

**Tech Stack:** Vue 3 + TS, Vitest, Capacitor 8 Kotlin plugins, Media3, Google Cast SDK.

**Spec:** `docs/superpowers/plans/2026-11-22-plex-support.md` ("Phase 9") + facts verified live on 2026-11-23 (below).

## Global Constraints

- Live tests only with the managed Plex Home profile "claude" on the user's server; never the owner account or its tokens; no writes to media; timeline/scrobble only through unit tests or blocked in e2e.
- Architecture test stays green: no `@/backends` import outside the session store/registry; no Plex SDK.
- Chat with the user in French; code, commits, docs in English.
- Each task ends with `npx vue-tsc --noEmit`, `npx vitest run` green and a commit; Kotlin tasks also `npm run android:build`.
- Phone installs only when the user asks: `ANDROID_VERSION_CODE=<installed+1>` (39 installed).

## Verified Plex facts (claude profile, 2026-11-23)

- Music sections have `type: 'artist'`; `type=8` artists, `9` albums, `10` tracks; `sort=random` works.
- Artist → `/children` = albums, `/allLeaves` = tracks; album → `/children` = tracks.
- Track part URL `/library/parts/{partId}/file.{ext}` (or the part `key`) answers Range (206). `/music/:/transcode/universal/start.mp3` answers 200 without Range even with `directPlay=1` (no seeking): use it only to convert.
- Music decision needs `X-Plex-Client-Profile-Name=Generic` + a `musicProfile` profile extra (else 400).
- Original download: part `key` + `?download=1` (200, attachment).
- BIF: `/library/parts/{partId}/indexes/sd`; only when the part has `indexes: "sd"` (404 otherwise).
- The claude profile has no playlists and no lyrics: these are unit-tested only.

## Review Focus

1. A queue saved before this change has no `streamRef`: Plex tracks must still play (universal stream fallback). → Task 2 test `falls back to the universal stream without a streamRef`.
2. FLAC/ALAC tracks on Cast or a quality cap: must convert, not direct play. → Task 2 test `converts when the container is not playable or a cap is set`.
3. A movie without generated previews must play without thumbnails, no error. → Task 4 test `no previews when the part has no index`.
4. Android Auto after switching from a Jellyfin to a Plex account must browse Plex, not the old server. → Task 6 Kotlin config replaces the previous one; TS test `pushes the Plex library config on account change`.
5. Cast from a Plex item must send a stream the Default Media Receiver plays (H.264/AAC, token in the URL). → Task 5 test `casts the web plan's media element URL`.

### Task 2: Plex MusicPort

**Files:** Create `src/backends/plex/music.ts`, `src/backends/plex/music.test.ts`; Modify `src/backends/plex/index.ts` (music on, `capabilities.music/lyrics = true`), `src/backends/plex/catalog.ts` (list `artist` sections), `src/domain/backend.ts` (`streamUrl(trackId, request, streamRef?)`), `src/store/audio-player-store.ts` (`AudioTrack.streamRef?`), `src/utils/audioTrack.ts`, `src/services/audioPlayerService.ts` (pass `streamRef`).

**Interfaces:**
- Consumes: Task 1 `streamRef`, `toLyrics`.
- Produces: `createPlexMusic(client: PlexClient): MusicPort`.

Endpoints: `artistAlbums` → `/library/metadata/{id}/children` (albums, newest year first); `artistTracks` → `/allLeaves`; `albumTracks` → `/children`; `playlistTracks` → `/playlists/{id}/items`; `randomTracks(lib, n)` → `/library/sections/{lib}/all?type=10&sort=random` window `{0,n}`; `lyrics(id)` → item's `streamType 4` stream `key` (null if none); `reporter(trackId)` → `/:/timeline` like video, no transcode to stop.
`streamUrl`: with a `streamRef` whose extension is in `request.directContainers` and no cap below the file bitrate → `client.url(streamRef)`; otherwise `/music/:/transcode/universal/start.{request.transcode.container}` with `path=/library/metadata/{id}`, `protocol=http`, `directPlay=0`, `directStream=1`, `musicBitrate=maxBitrate/1000`, `session`, profile name Generic and extra `add-transcode-target(type=musicProfile&context=streaming&protocol=http&container={c}&audioCodec={codec})`, token in the URL.

### Task 3: Plex downloads

**Files:** Create `src/backends/plex/downloads.ts` + test; Modify `src/backends/plex/index.ts` (`downloads: true`, `transcodedDownloads` per finding).

**Interfaces:** `planPlexDownload(client: PlexClient, request: DownloadRequest, item: PlexMetadata): Promise<DownloadPlan>`.
Original: `url = base + part.key + '?download=1'`, headers = client headers, `fileExtension` = part container, sidecar = chosen external text subtitle (`/library/streams/{id}`, format srt/vtt), markers from the item. Transcoded: try `/video/:/transcode/universal/start.mp4` with `protocol=http`, forced bitrate/size; if PMS refuses (decision not 1000/1001) fall back to the original and keep `transcodedDownloads: false`.

- [ ] Tests: `plans the original file with the token header`, `adds the chosen srt as a sidecar`, `copies intro/credits markers`, `transcode request uses the mp4 http stream` (or `falls back to the original`).
- [ ] Live check (claude): plan URL answers 200 with `content-disposition: attachment` (headers only, body cancelled).
- [ ] Commit `feat(plex): downloads`.

### Task 4: BIF seek-bar previews

**Files:** Modify `src/backends/plex/playback.ts` (`trickplay`), `src/backends/plex/types.ts` (`PlexPart.indexes?`), `src/composables/player/useNativePlayer.ts` (pass BIF), `android/.../TrickplayThumbnails.kt` (BIF source); Test `src/backends/plex/playback.test.ts`.

**Interfaces:** `trickplay(id, versionId)` → `{ format: 'bif', url, headers }` when the part has `indexes === 'sd'`, else `null`. - [ ] Tests: `previews from the part index`, `no previews when the part has no index`.
- [ ] Kotlin: BIF parse + lookup; `npm run android:build`.
- [ ] `capabilities.trickplay = true`; commit `feat(plex): BIF seek-bar previews`.
